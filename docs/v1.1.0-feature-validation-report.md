## 4. Model attribution 与历史 repair

- 模型唯一来源是 `turn_context.payload.model`；slug 原样保留，没有 Astra/Sol/Terra 等合并逻辑。无效或缺失字段保持无模型。
- Modern 由记录自己的 thread_id / turn_id / response_id 建立身份关联，绝不使用上一个 turn 的模型代替缺失 turn；跨 turn 切换与相同身份的矛盾证据有测试覆盖，冲突归 unknown。
- Legacy 依赖既有 legacy fact 的精确 source range、明确 thread/turn。`timeUncertain` 差值只在连续同一明确 turn、累计两端差值逐项匹配已有 usage 时允许归属；同 turn 的 model 冲突由 model_turns 冲突标记阻断。task 边界、解析问题、缺失 turn 或跨 turn 则清空连续性证据。
- Backfill/repair 只写模型 metadata/checkpoint，不调用 normalization，不修改 fact/active/identity/reconciliation/usage/time_status。重复扫描、重启、冲突、缺失 rollout 和修复幂等性测试通过。
- 原 rollout 缺失时 accounting 保留；没有模型证据的事实进入 unknown。已经可靠持久化的模型证据不会因文件缺失而被抹除。
- unknown 合法，不额外改变 partial 语义；正数 unknown 永远最后，零行省略。`codex-auto-review` 是独立模型，测试和原生界面均确认。

## 5. 周期与不变量

| 区域 | 周期 |
| --- | --- |
| Overview | today / thisWeek / thisMonth / total |
| By Model | today / quotaWeek / thisMonth / total |

Overview.thisWeek 保持当地自然周一 00:00 → Q，原始日期逻辑未改。By Model 首次进入默认 quotaWeek。Today、Month、Total 与 Overview 对应周期一致；Quota Week 不要求等于自然周。

所有模型聚合在同一个 SQLite transaction/snapshot、同一 active fact 循环、同一个 queryAt 完成。标量子查询不会使外层 fact 行倍增，关联键及索引用于身份查找。

每个有效周期满足 Σ known + unknown = period.totalTokens。total = input + output；cached/reasoning 不二次累加。后端 checked i64 处理累加溢出，share 用 i128 运算后才输出有界浮点百分比；Token 对外保持 decimal string，前端 formatter 使用 BigInt。share 显示一位小数，不强制舍入后合计 100.0%。

## 6. Quota Week

唯一边界来自当前 ProviderSnapshot.weeklyWindow 的 resetsAt 和 windowSeconds，经 App → hook/controller → IPC → aggregate 传递，不新增 Quota 请求。

必须为 604800 秒；start = resetsAt − windowSeconds；必须满足 start ≤ Q < resetsAt；只统计 `[start, Q)` 内既有 dated active facts。边界、Q 当下排除、自然周与额度周分离、Auto Review/unknown/零值不变量均有 synthetic 测试。

缺少窗口/reset、非法 reset、非七天窗口、未来起点、过期窗口、unavailable、signed_out、loading 或 stale 超出原 30 分钟有效期，quotaWeek 为 null。没有自然周 fallback。

hook 在 reset 或 stale 截止时触发失效。边界变更同步清空旧 quotaWeek、递增 revision，再发起查询；旧 revision 的异步响应丢弃。后端查询失败也清空额度周而保留其他可用历史周期。相关 reset/竞态/异常测试通过；隔离原生 signed-out 场景显示不可用占位。
