## 6. Updater 策略

V1.0.0 正式采用：**手动 GitHub Release 更新**。

- 删除前端 Tauri updater 检查、下载、安装和 relaunch 逻辑；
- 删除 Rust updater/process 插件注册、启动时后台检查及可用更新提示；
- 删除 updater endpoint、公钥、updater capability 和 updater artifacts；
- 托盘入口只打开 `https://github.com/bennick1/codex-monitor/releases`；
- CI/Release Preparation 执行 `check:updater-policy`，阻止主运行时重新出现上游 release URL、updater 插件或主动下载安装逻辑；
- Quota API 请求与 `QuotaFloat/0.1` User-Agent 保持不变。

历史文档中的 upstream URL、MIT 来源与 upstream remote 是保留证据，不属于运行时更新入口。

## 7. Identifier 策略

V1.0.0 继续保留 `app.quotafloat.desktop`，以兼容 preferences、window state 和 `token-statistics.sqlite3` 历史数据。当前统计事实不能全部从已删除原始日志重建，因此本轮不迁移 identifier。未来若迁移，必须作为独立版本的数据迁移任务处理。

## 9. 已知限制

1. V1.0.0 未进行平台代码签名或 Apple notarization；Gatekeeper/SmartScreen 可能提示，README 与 Release Notes 已披露。
2. Windows 人工验收的详细环境与逐项记录未进入仓库；只能据实引用用户给出的总体“通过”结论。
3. Universal macOS 构建可证明同时含 arm64/x86_64，不等于 Intel Mac 实机人工验收；本次 macOS 人工使用验收来自用户当前 Mac。
4. Token Statistics 是当前机器识别到的本地历史，不是账户官方、跨设备或云端全量；缺失历史会继续标记为不完整。
5. V1 保留 legacy identifier；未来 identifier 迁移、已安装入口迁移和签名体系均不在本轮范围。
6. 应用不提供自动更新，用户需手动从本项目 GitHub Releases 下载新版。
7. GitHub Actions 对部分 v4 action 给出 Node 20 runtime 弃用提示并已由 runner 强制使用 Node 24；本轮全部通过，但后续应升级相应 action major version。
