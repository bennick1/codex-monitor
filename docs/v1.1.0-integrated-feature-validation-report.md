### 4.2 五周期与数据证据

五周期 API 为 `today / quotaPeriod / last7Days / last30Days / total`：

- `today`：系统 IANA 时区下的有效本地日界到共同查询时点 Q，右开区间；
- `quotaPeriod`：有效 Provider weekly window 的 reset 减 604800 秒到 Q；无效、过期或缺失时为 null，不回退自然周；
- `last7Days`：`[Q - 604800 秒, Q)`；
- `last30Days`：`[Q - 2592000 秒, Q)`；
- `total`：保留既有 active facts、未来排除与 time-status 规则。

当前 Rust 回归覆盖纳秒级半开边界、春秋 DST、周一/月初跨界、空值/极大值、unknown 与逐周期 reconciliation。Overview 仍为 `today / thisWeek / thisMonth / total`，未改成滚动周期。

既有实施证据使用生产 aggregator 和只读数据库连接，将同一 SQLite snapshot 固定在内存后完成五周期模型和一致性核对；当前系统时间查询也完成 today / last7Days / last30Days / total reconciliation，数据库 integrity 与 schema 2 检查通过。该证据没有写生产数据库，也没有在 Git 中记录真实 Token、模型用量、Quota、reset 或截图。本轮没有重新读取或修改生产 SQLite，仅复用该已记录的只读证据，并以当前自动测试回归确认实现仍通过。
