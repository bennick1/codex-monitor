## 3. 关键技术限制：不要把合成 PNG 当分层源文件

单个最终像素一般可表达为 `C = alpha * F + (1 - alpha) * B`。只有 C、没有独立 F/B/alpha，不能唯一恢复原始透明字形层。因此：

- 不承诺从此 PNG 必定能无损提取一个可铺在任意背景上的“纯透明文字 PNG”。
- 不把抠出的灰底、白边当成通用文字 alpha，也不因换底后有色块继续寻找系统字体。
- 不使用 image generation、字体 OCR 识别猜测、全库字体搜索或手工新画字形来替换原图。

实施顺序：

**A. 能精确复合的独立字形层优先。** 若现有图层/算法已经可以在目标板面上逐像素复合回原件，直接复用；保留笔画与完整白边，不再额外叠 text-shadow、stroke、filter。

**B. 若 A 无法无损分离，直接采用“背景绑定的局部文字合成补片”。** 从固定原图文字区域保留字形、白边及无法分离的少量局部板面像素，只覆盖当前已修补的文字内部区域。补片与特定面板背景、状态、坐标成对使用，明确标记 `background-bound label patch`，不得谎称是纯文字透明层。

此 B 是本次边界审查允许的确定性实现手段，不是截图作弊：它只替换三个固定中文标签附近的视觉像素，运行时仍是三个真实按钮，且完整截图差异照常计算。

现有原图文字矩形/修补区域/归一化参数先保持。禁止扩大到边框灯带，禁止为了排除误差扩大诊断 mask。如果原标签白边确实超出原记录区域，先用原件证明并记录边界修正理由及前后覆盖坐标；完整比较区域永远不裁减。当前真实字体多出来的白边应先通过移除该视觉字体层清除，不能掩盖。

已对齐的切角、接缝、面板轮廓、灯边、底边保持原样。只修正文字视觉层及其原修补区域，绝不恢复“三个独立键帽”或重新设计整体外壳。

## 4. 局部补片与状态/语言的配对要求

每个资源必须有确定身份：`locale + labelKey + sourceState + renderState + panelBackgroundId`；只复用必要变体，沿用当前资源命名风格。

1. 标签键稳定：`overview` 永远只能显示「总览」，`models` 显示「按模型」，`turns` 显示「额度周」。选中另一个按钮时不能把「额度周」字图一起搬过去。
2. 不从显示文字反向推断 mode；继续由既有 mode 驱动标签/装饰与真实内容。
3. 三色原图均为“额度周选中”，只有这个状态有完整直接参考。对应三色的三片标签必须从各自原图保留，不任意互换。
4. “总览选中／按模型选中”及 hover/focus 没有相应冻结截图，沿用已经还原的同一状态规则，作为交互派生明确留证。不能声称未知的原始选中字形已被恢复。
5. 背景绑定补片不能直接覆盖在另一种亮度、渐变或颜色的面板上。派生状态使用背景匹配的变体；保持标签本身的已提取字形，不引入新的文字风格。不能为了消除贴片边缘而重新调整整个板面或边框。
6. 英文和非 Mecha 皮肤必须彻底关闭中文视觉资产及相关背景校正层，恢复真实文字。不得出现中文残留、双重标签、空按钮或错误语言。
7. 资源丢失、损坏、尚未解码或映射缺失时，可靠显示当前语言的真实文本；错误必须可诊断，不能用回退字体截图冒充精确还原通过。

## 5. 保留真实标签与按钮的可访问性

既有结构是 `role=group` 内的三个 `button type=button` 与 `aria-pressed`，不是本轮重构 ARIA Tabs 的授权。

推荐最小接入方式：

- 按钮保留当前事件和 pressed 状态。
- DOM 中保留来自当前语言表的真实标签 span。
- 中文视觉资产作为独立呈现层，`alt=""`、`aria-hidden="true"`、`pointer-events:none`、不可拖拽，不参与键盘焦点。
- 只有在 Mecha + zh-CN + 正确资产加载/解码成功时，真实标签才采用现有 visually-hidden/sr-only 模式；它仍应为按钮提供正确名称。
- 不用 display:none、visibility:hidden 或 aria-hidden 把唯一语义标签一起移除；不添加相互冲突的 aria-label/aria-labelledby/图片 alt 导致重复播报。
- 如沿用明确 aria-label 方案，只能保留一条有效命名路径，值必须来自同一语言表且等于可见标签文案；具体选择以最小改动为准。
- 资源失败时撤销视觉隐藏，显示真实文字；切语言/皮肤后旧图片 onload 不能反向把新标签隐藏。
- 保留 focus-visible、Enter/Space、点击隔离；图片或补片不得改变命中盒。

**风险说明不能省略：** 有正确的可访问名称，不等于图片文字自动满足全部无障碍要求。固定字图对字体替换、仅文字放大和个性化前景色有局限，不能宣称“图片文字与真实文本完全等价”或“全套 WCAG 已通过”。在宿主支持的 forced-colors 等既有可访问模式下，局部退回真实文字，不为本任务新建设置系统。常规页面缩放和 DPR 1/2 要检查可读性及图像缩放，不把 1× 位图插值放大称为真实高分辨率文字。

参考依据：W3C [Button Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/button/)、[Accessible Names](https://www.w3.org/WAI/ARIA/apg/practices/names-and-descriptions/)、[Images of Text 的限制](https://www.w3.org/WAI/WCAG21/Understanding/images-of-text-no-exception)。仅用于上述边界，不据此擅自宣称合规例外已成立。
