# Codex Monitor 1.4.0

本版带来侧边栏、在线更新，以及 macOS 的“仅菜单栏”展示模式。原有悬浮窗、四套皮肤和本机 Token 统计继续保留。

## macOS 菜单栏模式

- 在“展示模式”中选择“仅菜单栏”，即可在菜单栏查看剩余额度；左键开关详情，右键打开操作菜单。
- 额度按账户实际提供的周期显示。只有周额度的账户只显示周额度，不显示空的短周期栏；有两个周期时可选择短周期、周或同时显示。
- 展开直接复用现有完整卡片，保留额度区、总览、按模型、额度周及 Default、Blur、Computer、Mecha Light 四套皮肤。
- 关闭详情面板后仍会正常刷新额度，通常每五分钟刷新；手动刷新、临近重置和失败重试沿用各自调度规则。
- 可随时切回悬浮窗或侧边栏。升级和重启保留已有展示模式、皮肤与设置，不会强制改为仅菜单栏。

“仅菜单栏”是 macOS 功能。Windows 保留悬浮窗、侧边栏、系统托盘和更新入口，本版没有新增相同的 macOS 菜单栏体验。

## 侧边栏

- 新增右侧、左侧或顶部贴靠，悬停拉手展开，支持外观、缩放、背景透明度和玻璃效果设置。
- 展示 Codex 额度及可用的账户统计，并可选择启用 DeepSeek 的独立登录与数据视图。缺失或读取失败的数据会明确显示状态。
- 账户统计与本机 Token 统计保持独立；Token 数量不用于估算剩余额度。

## 在线更新与首次安装

- **已公开的 v1.3.1 不带 updater，须从本项目 Releases 手动下载并安装 1.4.0，才能使用后续在线更新。** 安装前退出旧应用，保留已有配置和统计数据；不要同时运行两份应用。
- 新版本默认在后台检查更新，可关闭自动检查，也可从“软件更新”主动检查。后台检查不会自动下载或安装；下载由用户发起，安装和重启须再次确认。
- 正式更新包经过 Tauri updater 签名校验。更新窗口仍提供版本下载页入口。

## 安装提示与验证范围

- macOS 安装包为 Universal（Apple Silicon / Intel），Windows 安装包为 x64。
- **本版没有 Apple Developer ID 签名或公证，也没有 Windows Authenticode 签名。** macOS 的本地 ad-hoc 签名不代表 Apple 验证；系统仍可能显示 Gatekeeper、未知发布者或 SmartScreen 提示。Tauri updater 签名只用于验证更新包来源和完整性，不替代这些系统签名。
- 仅从 [bennick1/codex-monitor Releases](https://github.com/bennick1/codex-monitor/releases) 下载，并核对随包提供的 `SHA256SUMS`。
- Windows 原生升级、Mac Intel 实机、多屏/混合 DPI、睡眠唤醒等仍待相应设备验证；CI 编译和打包成功不等于实机通过。详细证据及未覆盖项见 [1.4.0 发布准备记录](https://github.com/bennick1/codex-monitor/blob/main/docs/RELEASE-1.4.0-PREPARATION.md)。
