# 侧边栏实现与验收记录

日期：2026-10-01。开发分支：`codex/side-dock-analysis`，基于 `9b7e37c`，尚未提交或发布。参考本机 codenotch `6e8b0f8` 的交互、账户统计字段及 DeepSeek 网站读取流程。

## 实现范围

- 保留悬浮窗；托盘“展示模式”和悬浮卡片的齿轮可切换侧边栏。侧边模式隐藏托盘图标，齿轮提供设置、刷新、登录及退出入口。
- 默认右侧，支持左侧；拉手可见尺寸为 6×48，独立实色背景。原生窗口随把手、竖条、详情、设置缩放，分别为 8×56、64×288、344×480、376×580 逻辑像素，使用显示器工作区定位。展开背景不透明度支持 20%–100%。竖条四角圆润，底部圆弧悬停显出齿轮；顶部暂不占位。
- 悬停圆环打开详情，保留点击与键盘入口。Pro 系列在侧边栏仅显示周额度，缺失时显示未知；其他订阅保留 5 小时和周额度。账户累计、峰值、最长对话、连续天数和每日 Token 紧凑展示，本机 SQLite 统计保留在原悬浮模式。
- DeepSeek 使用独立网站会话。资金圆环按 `余额 / (余额 + 累计费用)` 显示剩余；费用、请求数、密钥数量及每日图表使用平台统计。零分母和未知字段显示 `—`。
- 鼠标跨入详情、打开菜单、键盘操作或固定展开时保持可用；点击设置外部或设置失焦时收起，其余鼠标离开延迟 450 毫秒收起。重新打开解除鼠标穿透并恢复入口。

主要代码：`Sidebar.tsx` 与 `sidebar.css` 负责视图及交互；`sidebar.rs` 管理窗口；`account_usage.rs`、`deepseek.rs` 和 `deepseek-read.js` 读取并归一化账户统计。原有本机 Token 数据库结构未变。macOS 外部点击监听将 Tauri 已锁定的 `block2 0.6.2` 列为直接依赖，无新增版本。隐私边界见 [PRIVACY.md](../PRIVACY.md)，资源许可见 [第三方说明](THIRD-PARTY-NOTICES.md)。
