## 排查结论

历史记录将界面显示旧周期的问题定位为运行了旧 release 包：原生 WebView 加载包内资源，而非当前工作树中的前端资源。排查同类问题时，应先核对实际可执行文件、WebView URL 和开发服务器对应的工作树，再判断生产代码是否需要修改。浏览器预览不能替代原生 App 验证。

模型页的额度周与总览的自然周使用不同数据来源：

| 展示位置 | 数据来源 |
| --- | --- |
| 模型页今日 | modelStatistics.periods.today |
| 模型页按额度周 | modelStatistics.periods.quotaWeek |
| 模型页本月 | modelStatistics.periods.thisMonth |
| 模型页总计 | modelStatistics.periods.total |
| 总览本周 | snapshot.thisWeek |

模型页默认周期为 `quotaWeek`，中英文标签分别为“按额度周”和“Quota Week”。总览保留自然周。对照后端与 UI 时，应比较同一次查询的结果，不能把活跃采集期间不同时点的数值差异当成绑定错误。
