# v1.1.0 Windows 人工验收方法

只使用 [发布验证报告](v1.1.0-release-validation-report.md) 所列 Release Build Source 的 Actions `Codex-Monitor-1.1.0.exe`；先验证 SHA256SUMS。按普通用户安装，不要求管理员权限。不要把真实 Token、Quota、账号、截图或详细机器资料填入公开仓库。

- [ ] **已有 v1.0.0：** 退出旧实例，保留一致性备份，直接安装 v1.1.0，不先卸载；比较历史设置和历史 Token，确认 Token Statistics 完成升级、By Model 出现、Quota Week 正常；退出重启后再次检查。
- [ ] **没有 v1.0.0：** 执行 fresh install，启动并确认初次扫描完成；升级项标为不适用，不声称验证过升级。
- [ ] **Quota：** 在本机已有 Codex 登录条件下检查额度、reset 展示；缺失窗口或未登录时应显示相应不可用状态。
- [ ] **Overview：** 检查 Today / thisWeek / Month / Total 与升级前历史保留情况。
- [ ] **By Model：** 检查 model、Token、share；默认 Quota Week；Today / Month / Total 可切换。
- [ ] **Quota Week：** 有有效周额度窗口时检查显示；不可用时显示占位，不应拿自然周代替。
- [ ] **Unidentified：** 对已有无法可靠归属的历史检查显示；没有此类历史时记为未覆盖，不制造真实数据。
- [ ] **窗口：** Hover 展开/收起、Tray 显示/隐藏与退出、Always-on-top 开关、Drag 均正常。
- [ ] **Restart：** 退出重启后设置、历史和模型统计正常；存在新本地使用记录时检查增量更新。
- [ ] **卸载：** 完成前述检查并退出应用后，使用标准卸载入口，确认正常结束；不要手动删除历史数据库来绕过问题。

用户反馈只需：**通过 / 不通过**；如不通过，提供脱敏的失败步骤。未覆盖项单独说明。CI install/start/uninstall smoke 不能代替本清单。v1.0.0 不支持读取升级后的 schema 2 Token 数据库，不以回退旧版验证“无损降级”。
